# Blake3.Managed.Baseline

A **frozen snapshot** of `src/Blake3.Managed`, compiled under the assembly name
`Blake3.Managed.Baseline`. It exists for one reason: to be the control in an A/B benchmark.

## Why this exists

On a laptop that thermally throttles, comparing today's numbers against numbers recorded in an
earlier session is not evidence. Even a ratio against a fixed external reference is not enough
once our path is multithreaded and the reference is not — the ratio itself drifts with the
thermal state.

The only reliable control is **old code and new code measured back to back in the same process,
in the same session, under the same thermal conditions**. That is what this project provides.

The shipped NuGet package cannot serve this purpose: it and the project both produce an assembly
with the simple name `Blake3.Managed`, and the default `AssemblyLoadContext` will not load two
assemblies with the same simple name. An extern alias resolves the compile-time ambiguity but not
the load-time one. Renaming the assembly here avoids the problem entirely, and keeps benchmarked
calls as ordinary statically compiled calls — no reflection or cross-context marshalling to
distort small-input measurements.

## Snapshot provenance

Taken from commit `21dc244` (tag `v1.2.1` + 1), 2026-07-29 — immediately before the optimization
pass began. This is the "before" the optimization work is measured against.

## Refreshing the snapshot

Refresh only when you want to move the goalposts, for example after landing an improvement and
wanting subsequent work measured against the new, better code. From the repository root:

```bash
rm -rf src/Blake3.Managed.Baseline/src
mkdir -p src/Blake3.Managed.Baseline/src
cp -r src/Blake3.Managed/*.cs src/Blake3.Managed.Baseline/src/
cp -r src/Blake3.Managed/Internal src/Blake3.Managed.Baseline/src/
```

Then update the provenance commit above, and note in the commit message that baseline numbers
before and after the refresh are not comparable.

## Do not edit the sources here

Everything under `src/` is generated by the copy above. Edits belong in `src/Blake3.Managed`.
